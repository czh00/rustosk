# RustOSK — Tauri 智慧螢幕小鍵盤 ⌨️

> 本專案是原 C# 版本 OSK 的 **Rust + Tauri** 強力進化版。結合了 Rust 的極致效能、Windows API 的深度整合，以及 Web 技術的流暢 UI，打造出反應最快、最智慧的虛擬鍵盤體驗。目前版本已進入穩定發佈階段，支援多種現代化功能。

---

## 🌟 核心特色

### 🚀 極速啟動與零負載
採用 **Rust + Webview2 (Tauri)** 架構，啟動速度比傳統 .NET 版本更迅速，且在非輸入狀態下幾乎不佔用 CPU 資源。

### ⌨️ 多樣化佈局與動態標籤
| 模式 | 內容 |
|------|------|
| **100% 全鍵盤** | 包含完整數字九宮格、導航鍵與功能鍵區，間距經過精心校準。 |
| **60% 精簡版** | 適合螢幕空間有限的情境，配合 `Fn` 鍵可觸發完整功能。 |

- **動態標籤**：按下 `Shift` 或 `Fn` 時，按鍵中心標籤會實時更換為對應字元（例如 `a` 變 `A`、`1` 變 `!`），讓輸出結果一目了然。
- **靜態多角標籤**：專注於視覺對比與細節，包含客製化 Numpad 九宮格邏輯（自動在導航與數字間切換光暈）。

### 🔍 深度輸入焦點偵測
整合 **UIA (UI Automation)** 與 **Win32 Caret 偵測**，支援 Chrome、VS Code、CMD、Telegram 等多種複雜軟體，精準實現「點擊輸入框自動彈出」、「失去焦點自動隱藏」。

### 📋 智慧標題欄 (智慧二合一)
標題欄左側分為上下兩行顯示：
- **行 1**：當前焦點程式名稱與輸入法狀態（英文 / 中文）。
- **行 2**：「📋」剪貼簿即時摘要，支援文字預覽。

### ⚡ 實體鍵盤同步回饋 (New)
具備全域鍵盤掛鉤（Global Hook），當按下實體鍵盤時，虛擬鍵盤上的對應按鍵會同步高亮，提供直觀的視覺反饋。

### ⚙️ 深度自定義編輯模式 (New)
進入編輯模式後，您可以：
- **拖拽交換**：直接用滑鼠拖曳按鍵對調位置。
- **角落功能自定義**：長按按鍵可設定四個角落的顯示內容與實際發送的鍵值（支援 `Ctrl+C` 等組合鍵）。

### 📍 高彈性置頂與 Tray 互動
- **自動隱藏**：智慧追蹤輸入焦點。
- **固定模式**：點擊 `📍` 強制鎖定在最上層。
- **Tray 隱藏鎖**：透過系統列圖示左鍵點擊，可快速「手動暫時隱藏」鍵盤並防止其因焦點改變而彈回。

## 🔘 工具列按鈕說明

| 按鈕 | 說明 |
|------|------|
| `💻 / 📱` | 切換 **精簡 (60%) / 全鍵盤 (100%)** 佈局 |
| `🗔 / 🗖` | 切換 **動態 / 靜態** 標籤模式（顯示於按鍵中央或角落） |
| `📍 / 📌` | **固定 / 自動隱藏** |
| `🌙 / ☀️` | **深色 / 淺色** 主題切換（包含高對比角落色彩優化） |
| `↺` | **恢復預設值**：清除所有快取與 `osk.ini` 並重新啟動 |
| `⚙` | **編輯模式**：進入後可拖拽按鍵或長按自定義功能 |
| `🆘` | **SOS 緊急備援**：當遇到 UAC 或權限視窗時，自動呼叫系統內建 `osk.exe` |
| `✕` | **安全關閉**：徹底釋放資源，不留殘留處理程序 |

## 🛠️ 技術架構

- **Backend**: Rust + [Tauri v2](https://v2.tauri.app/)
- **Frontend**: Vite + TypeScript + Vanilla CSS
- **API 整合**: 
    - `windows-rs`: 深度呼叫 Win32 API。
    - `Imm32`: 精準偵測輸入法狀態。
    - `UI Automation`: 捕捉瀏覽器與現代應用的焦點狀態。

## 📂 開發與執行

### 環境需求
1. 安裝 [Rust](https://rustup.rs/)。
2. 安裝 [Node.js](https://nodejs.org/)。

### 執行步驟
1. 安裝依賴：`npm install`
2. 啟動開發者模式：`npm run dev`
3. 建置發佈版本：`npx tauri build --no-bundle`

*(註：發佈用的可攜式執行檔位於 `release/rustosk.exe`。)*

## 📂 專案結構

```text
rust/
├── src/                # 前端原始碼 (TypeScript + CSS)
├── src-tauri/          # 後端原始碼 (Rust)
│   ├── src/
│   │   ├── system/     # Windows API 整合模組
│   │   └── bin/        # 輔助工具 (如 UIA 測試)
├── release/            # 發佈用執行檔
└── index.html          # 前端進入點
```
